# Help-desk knowledge base

Short articles for first- and second-line support. Each one has the same sections: symptoms,
quick checks, fix, when to escalate, prevention, and the scripts in this repository that help.
The method behind them is in [docs/method.md](../method.md).

| --- | --- |

| [03 Wi-Fi will not connect](03-wifi-will-not-connect.md) | "The Wi-Fi says no internet." |
| [04 VPN fails](04-vpn-fails.md) | "The VPN connects but I can't open the shared drive." |
| [05 Printer offline and print spooler](05-printer-offline-and-spooler.md) | "The printer says offline." |
| [06 Disk full](06-disk-full.md) | "My laptop says it's out of space." |
| [07 Slow PC triage](07-slow-pc-triage.md) | "My computer is really slow." |
| [08 Outlook profile and OST problems](08-outlook-profile-and-ost.md) | "Outlook is stuck on loading profile." |
| [09 DNS resolution failures](09-dns-resolution-failures.md) | "The intranet can't be found." |
| [10 New starter checklist](10-new-starter-checklist.md) | "Someone joins on Monday." |

Commands in the articles use example names such as `sara.ali`, `corp.example.com` and
`10.1.2.50`. Replace them with your own.
